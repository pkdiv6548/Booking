# TripNest Booking Website

A multi-page travel-booking frontend prototype inspired by common accommodation-booking patterns.

## Stack and constraints
- Plain HTML, CSS, and vanilla JavaScript.
- Each major screen has its own .html file; do not turn the site into a single-page application.
- Shared styling: assets/styles.css.
- Shared interactions: assets/app.js.
- Persistent prototype identity: TRIPNEST paper-plane logo, navy header, blue accents, and consistent typography.
- Use GitHub as the only development workspace for this frontend phase.

## Run locally
Open index.html in a browser, or enable GitHub Pages in repository settings and publish from the main branch.

## Current prototype routes
- index.html — homepage and stay search
- stays.html — accommodation search results and filters
- property.html — property details
- booking.html — booking flow
- login.html, register.html, profile.html — account screens
- trips.html, wishlist.html — traveller dashboard
- flights.html, cars.html, experiences.html, airport-transfers.html, offers.html — travel categories
- help.html, privacy.html — support and policy screens

## Prototype scope
Search, filtering, saved items, modals, and demo booking steps may run in the browser. Listings and prices are sample data. No real reservations or payments are processed. This is an independent prototype and is not affiliated with Booking.com.
